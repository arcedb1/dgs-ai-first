-----------------------------------------------------------------------
[USUÁRIO]
-----------------------------------------------------------------------
Você é um Delivery Manager da DB1.
Crie um BOARD DE TRACKING para acompanhar o status de todas as specs do
projeto NovaTech Assistant (Spec Driven Development).

OBJETIVO
Um board prático onde qualquer membro do time veja, em segundos, o status
atual de cada spec de cada módulo.

FLUXO DE STATUS (colunas do kanban / valores de status)
Rascunho → Em Revisão → Aprovada → Em Implementação → Validada

ITENS INICIAIS (5 módulos)
1. Pipeline de ingestão de documentos
2. API de busca (query endpoint)
3. API de feedback (atendente reporta resposta incorreta)
4. Bot do Teams (interface conversacional)
5. Painel web (dashboard de métricas e histórico)

CAMPOS POR ITEM
- Módulo
- Artefato SDD atual (requirements.md / plan.md / tasks.md)
- Status (uma das 5 colunas acima)
- Responsável atual (Product Specialist / Tech Lead / Dev / QA)
- Próximo checkpoint humano pendente
- Última atualização
- Observações / bloqueios

ENTREGÁVEL
Crie o board como um arquivo utilizável. Prefira UM dos formatos:
(a) uma planilha .xlsx com uma aba "Board" (visão kanban por status) e uma
    aba "Detalhe" (uma linha por spec com todos os campos), com formatação
    condicional por status e filtros; OU
(b) um kanban visual em HTML/Markdown, se preferir algo mais leve.
Popule as 5 specs como itens iniciais, todas começando em "Rascunho"
(ajuste se o contexto indicar outro ponto de partida) e com o responsável
coerente ao artefato inicial (requirements → Product Specialist).
Ao final, gere o arquivo na minha pasta e me mostre para abrir. Mantenha
simples e imediatamente utilizável pelo time — não sobrecarregue com campos
supérfluos.

-----------------------------------------------------------------------
[ASSISTENTE - entrega]
-----------------------------------------------------------------------
Board pronto. É um kanban HTML autocontido (abre no navegador, sem instalar
nada).

Arquivo gerado: board-specs-novatech.html

O que ele tem:
- 5 colunas seguindo o fluxo SDD: Rascunho → Em Revisão → Aprovada →
  Em Implementação → Validada.
- As 5 specs como cards, todas em "Rascunho", artefato requirements.md e
  responsável Product Specialist (coerente com o ponto de partida do SDD).
- Cada card mostra: módulo, artefato SDD, responsável, próximo checkpoint
  humano, última atualização e observações/bloqueios.
- Interativo: arraste o card entre colunas para mudar o status (a data de
  atualização muda sozinha), busca por texto e filtros por responsável/artefato.
  As mudanças ficam salvas no navegador.

Perguntas de acompanhamento oferecidas: adicionar botão para editar
responsável/observação direto no card, ou gerar uma versão .xlsx paralela.
